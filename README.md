# Smart-Leave-Approval-Workflow-Website-
SmartLeave is a Flask-based role-based leave management system (Student/Faculty/Admin) with TOTP MFA login, an ML text classifier (scikit-learn) that auto-tags leave reasons as Medical/Personal/Urgent, auto-escalation for long or urgent leaves, admin analytics dashboards, and an immutable audit log. Supports SQLite &amp; MySQL.
